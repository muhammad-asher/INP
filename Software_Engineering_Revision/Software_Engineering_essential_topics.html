🏢 Software Engineering Essential Topics

For 3-4 Years Experience Engineers

1. System Design (HLD & LLD)

📈 Scalability & Load Balancing

Horizontal Scaling (add servers), Vertical Scaling (upgrade one server). Load balancing distributes traffic: Round Robin (equal), Least Connection (busy-aware).
Real Example: Netflix handles millions of users: horizontal scaling (1000s servers) + load balancers route traffic across data centers.

💾 Caching Strategies

Write-Through (write to cache & DB), Write-Back (write to cache, async to DB), Cache-Aside (app manages cache). Redis/Memcached common.
Real Example: User profile: cache in Redis (100ms vs 1s DB), expire after 1 hour.

🗄️ Database Sharding & Partitioning

Split data across multiple databases by criterion (user_id range, geography). Increases capacity, complexity of queries increases.
Real Example: 100M users split across 10 shards: shard 0 has users 0-10M, fast lookups.

⚖️ CAP Theorem

Consistency (all nodes same data), Availability (always responsive), Partition tolerance (network failures). Pick 2 of 3. Strong vs Eventual Consistency.
Real Example: Bank (Consistency > Availability), Social media (Availability > Consistency).

🏗️ Microservices vs Monolithic

Monolith: single codebase, shared DB (simple, tight coupling). Microservices: independent services, own DB (scalable, complex deployment).
Real Example: Amazon: user-service, order-service, payment-service deployed independently.

📡 Communication Patterns

REST (HTTP, simple), gRPC (fast, binary), GraphQL (query language), WebSockets (real-time). Choose based on use case.
Real Example: API → REST, Mobile app → gRPC, Real-time chat → WebSockets.

📨 Message Queues

Kafka (high throughput, distributed), RabbitMQ (reliable, routing). Decouple producer-consumer, handle spikes.
Real Example: User signup → send welcome email: don't block, queue event, email service processes async.

🚦 Rate Limiting & Throttling

Prevent abuse: allow 100 requests/min per user. Token bucket algorithm common. Returns 429 Too Many Requests.
Real Example: API: 1000 requests/day free tier, 10000 for paid. Prevents bot attacks.

🆔 Distributed ID Generation

Snowflake algorithm (Twitter): timestamp + machine ID + sequence, generates 64-bit unique IDs. UUID alternative (collision rare but 128-bit).
Real Example: Generate unique order IDs across 100 servers without central DB.

2. Clean Code, Architecture & Design Patterns

🎯 SOLID Principles

S (Single Responsibility), O (Open-Closed), L (Liskov Substitution), I (Interface Segregation), D (Dependency Inversion). Best practices for maintainable code.
Real Example: User class shouldn't handle both user logic AND database queries (violates SRP).

🎨 Design Patterns

Singleton, Factory, Builder, Observer, Strategy, etc. Proven solutions to common problems. Know creational (Factory, Builder), structural (Adapter, Decorator), behavioral (Observer, Strategy).
Real Example: Payment processing: Strategy pattern for different payment methods (PayPal, Stripe, etc).

🌐 Domain-Driven Design (DDD)

Focus on business logic. Entities (with ID), Value Objects (no ID), Aggregates (root entity), Repositories (data access).
Real Example: Order aggregate contains OrderLineItems, focus on order business logic not DB schema.

🏛️ Hexagonal Architecture

Business logic at center, external concerns (DB, API) at periphery. Dependency inversion: core depends on adapters.
Real Example: Core business logic doesn't know if using PostgreSQL or MongoDB, adapter abstracts it.

💉 Dependency Injection & IoC

Inject dependencies rather than creating inside. Container manages lifecycles. Improves testability (mock dependencies).
Real Example: Service depends on UserRepository: pass as constructor argument, not create inside.

🚀 Test-Driven Development (TDD)

Write test first, then implementation. Red (test fails) → Green (test passes) → Refactor. Higher code quality.
Real Example: Test login behavior before writing UserService logic.

3. Databases

🔒 ACID Properties & Isolation Levels

Atomicity (all or nothing), Consistency (valid state), Isolation (concurrent independence), Durability (persistent). Isolation levels: Read Uncommitted → Serializable.
Real Example: Transfer money: either both debit+credit happen (atomicity) or nothing.

📑 Indexing

B-Tree (most common), Hash (equality), Composite (multiple columns). Speeds up SELECT, slows INSERT/UPDATE. Trade-off.
Real Example: Query users by email: index on email → O(log n) vs O(n) full scan.

🗄️ SQL vs NoSQL

SQL (structured, joins, ACID), NoSQL (flexible schema, horizontal scaling). PostgreSQL (relational), MongoDB (document), Cassandra (wide column).
Real Example: User profiles with varied fields → MongoDB flexible schema vs PostgreSQL rigid.

🔀 Normalization vs Denormalization

Normalization (no data duplication, 3NF), increases joins. Denormalization (store computed/duplicate data), faster queries, harder updates.
Real Example: Cache user_count in profile: denormalization, update on follow/unfollow.

🔄 Replication Strategies

Master-Slave (master writes, slaves read), Multi-Master (multiple writes). Improves availability & read throughput.
Real Example: Primary DB in US, replica in Europe for local reads.

⚙️ Concurrency Control

Pessimistic (lock before change), Optimistic (check version before update). Pessimistic safe but slower, optimistic fast but conflicts.
Real Example: Edit conflict: two users editing same post, use version number to detect.

4. Data Structures & Algorithms

📊 Fundamental Structures

Array (O(1) access), LinkedList (O(n) access), Stack (LIFO), Queue (FIFO), Hash Table (O(1) avg). Choose based on operations needed.
Real Example: Undo button → Stack, Queue of jobs, Employee lookup by ID → Hash Table.

🌳 Trees & Graphs

BST (sorted, O(log n) search), AVL/Red-Black (balanced), Graph (BFS/DFS traversal). Essential for many problems.
Real Example: Autocomplete → Trie, Route finding → BFS on graph.

⚡ Relevant Algorithms

Sorting (Merge, Quick, Heap), Binary Search (log n), Dynamic Programming (optimal substructure), Greedy (local optimal).
Real Example: Find median of stream → heap, Longest substring → sliding window, Coin change → DP.

📈 Big O Notation

Time complexity: O(1), O(log n), O(n), O(n log n), O(n²). Space complexity similar. Always know worst case.
Real Example: Processing 1M items: O(n) = 1s, O(n²) = 11 days. Choose wisely!

5. Distributed Systems Concepts

🤝 Consensus Algorithms

Paxos, Raft: ensure agreement across nodes despite failures. Critical for distributed databases, leader election.
Real Example: 5 replicas decide leader: 3 must agree (quorum), fault-tolerant.

👑 Leader Election

One node coordinates cluster (leader). If fails, new election. Complex in distributed environment.
Real Example: Database master fails, automatic election chooses new master to prevent split-brain.

⏱️ Clock Synchronization

NTP (Network Time Protocol) synchronizes clocks. Logical clocks (Vector Clocks) order events causally.
Real Example: Distributed tracing: order logs from multiple servers using logical clocks.

🛡️ Circuit Breaker Pattern

Prevent cascading failures. States: Closed (working), Open (failing, reject), Half-Open (test). Essential for resilience.
Real Example: Service A calls Service B: B fails → circuit opens → A fails fast rather than hanging.

🔄 Idempotency

API call produces same result if retried. Critical for distributed systems (network failures cause retries).
Real Example: Payment API: idempotency key prevents duplicate charges on retry.

6. Networking & Security

🌐 HTTP Versions

HTTP/1.1: sequential requests. HTTP/2: multiplexing (multiple requests in parallel). HTTP/3: QUIC protocol, faster.
Real Example: Load 100 resources: HTTP/1.1 = slow, HTTP/2 = parallel = fast.

🤝 TCP/IP Handshake

SYN → SYN-ACK → ACK establishes connection. Slow Start gradually increases window size to avoid congestion.
Real Example: High latency connections: multiple round trips, slow start ramps up gradually.

🔍 DNS Resolution

Domain name → IP address lookup. Recursive query: client → resolver → root → TLD → authoritative. Cache at each step.
Real Example: User types google.com: browser queries local cache, ISP resolver, root nameserver, etc.

🔐 Authentication & Authorization

OAuth 2.0 (third-party), OIDC (authentication), JWT (tokens), SAML (enterprise). Choose based on use case.
Real Example: Login with Google: OAuth 2.0, your app gets token, validates with Google.

🔒 HTTPS/TLS Handshake

Public key exchange, session key negotiation, encrypted communication. Always use HTTPS in production.
Real Example: Browser verifies server certificate, establishes secure connection before sending credentials.

⚠️ OWASP Top 10 Vulnerabilities

SQL Injection (parameterized queries), XSS (sanitize output), CSRF (tokens), authentication flaws, sensitive data exposure, etc.
Real Example: SQL Injection: "' OR '1'='1" bypasses login, use PreparedStatement instead.

7. DevOps & Cloud Awareness

🔄 CI/CD Pipelines

Continuous Integration (code merged, tested), Continuous Deployment (auto-deploy if tests pass). Jenkins, GitHub Actions, GitLab CI.
Real Example: Push code → GitHub → CI tests → if pass, deploy to staging & production.

🐳 Docker Containerization

Dockerfile builds image, containers run instances. Lightweight vs VMs. Reproducible environments.
Real Example: App works on dev but fails on prod: Docker ensures identical environment.

⚙️ Kubernetes Basics

Pod (container group), Service (network exposure), Deployment (replicas). Orchestrates containerized apps, auto-scaling.
Real Example: 100K users: Kubernetes scales to 10 replicas, distributes traffic, handles failures.

☁️ Cloud Fundamentals (AWS/Azure/GCP)

Compute (EC2, App Engine), Storage (S3, Cloud Storage), Networking (VPC), Serverless (Lambda). Pay-as-you-go model.
Real Example: Upload video → S3, Lambda processes → thumbnail cached → CDN serves globally.

📝 Infrastructure as Code (IaC)

Terraform, Cloudformation define infrastructure in code. Version control, reproducible, test before deploy.
Real Example: Production setup in code: database, servers, networks reproducible across environments.

👁️ Observability

Logging (ELK stack), Metrics (Prometheus), Tracing (Jaeger). Monitor system health, debug issues.
Real Example: Request slow: trace shows 1s in database query, 2s in external API call.

8. Soft Skills & Behavioral

💬 System Design Interview Approach

Clarify requirements → Propose high-level design → Deep dive into components → Discuss tradeoffs. Be clear, ask questions.
Real Example: Design Twitter: clarify DAU, TPS, read-write ratio before diving into sharding strategy.

👥 Mentorship & Code Reviews

Give constructive feedback, ask questions, don't criticize. Receive feedback gracefully, learn from others.
Real Example: Review: "Good logic, but could be clearer with a helper method" vs "This is wrong".

📋 Agile Methodologies

Scrum (sprints, standups), Kanban (continuous flow). Adaptive planning, regular feedback, iterate.
Real Example: 2-week sprint: plan → daily standup → demoes → retrospective for improvements.

📢 Stakeholder Communication

Tailor message to audience (technical vs business), clear timelines, manage expectations. Essential for career growth.
Real Example: To CEO: "Shipping in 2 weeks". To engineer: "Need to refactor DB schema, estimated 100 hours".
