☕ Java Essential Topics

Complete Guide with Real-World Examples

1. Core Java Fundamentals

🎯 OOP Principles

The four pillars of object-oriented programming: Encapsulation (hiding details), Inheritance (code reuse), Polymorphism (multiple forms), Abstraction (showing essential features).
Real Example: A Vehicle class has an abstract method start(). Car and Bike inherit from it and implement their own start() logic - that's polymorphism.

🔐 Access Modifiers

public (accessible everywhere), private (only inside class), protected (same package + subclasses), default (same package only).
Real Example: Bank keeps account balance as private so direct modification isn't possible. Access is only through public methods like withdraw().

📝 String Handling

String is immutable (can't change), StringBuilder is mutable (can change - fast), StringBuffer is mutable & thread-safe (slow). Use StringBuilder in loops.
Real Example: Building a dynamic SQL query in a loop: use StringBuilder instead of concatenating strings, saves memory and time.

⚠️ Exception Handling

Checked exceptions (IOException) must be caught. Unchecked exceptions (NullPointerException) are optional. Use try-with-resources for automatic resource closing.
Real Example: Reading a file: try (BufferedReader br = new BufferedReader(new FileReader("file.txt"))) auto-closes the file even if exception occurs.

2. Collections Framework & Generics

📚 List, Set, Map Differences

List allows duplicates (ArrayList-fast lookup, LinkedList-fast insertion), Set no duplicates (HashSet-O(1), TreeSet-sorted), Map key-value pairs (HashMap-fast, TreeMap-sorted).
Real Example: User contact list = List, Unique user IDs = Set, User details (id→name) = Map.

🔑 HashMap Internal Working

HashMap uses hash function to compute index, stores in buckets. Hash collision handled via chaining (Java 8+: linked list to red-black tree). Load factor default 0.75.
Real Example: Email → User ID mapping. Hash of "user@email.com" determines storage bucket.

🎭 Comparable vs Comparator

Comparable is default sorting (implement compareTo()), Comparator is custom sorting (implement compare()). Multiple comparators possible.
Real Example: Student objects: sort by marks (Comparable) or by name (Comparator).

🧬 Generics & Wildcards

Generics ensure type safety at compile time. List<? extends Number> accepts Number & subclasses. Type erasure removes generic info at runtime.
Real Example: List<String> prevents adding Integer accidentally. Caught at compile time, not runtime.

3. Java 8+ Features (Functional Programming)

⚡ Lambda Expressions

Lambda reduces boilerplate code. Syntax: (parameters) → expression. Works with functional interfaces (single abstract method).
Real Example: Instead of anonymous class: list.sort((a, b) → a.compareTo(b)); vs traditional Comparator.

🌊 Stream API

Functional way to process collections. Intermediate ops (map, filter, flatMap) are lazy. Terminal ops (collect, forEach, reduce) trigger execution.
Real Example: Filter adults & get names: list.stream().filter(p → p.getAge() >= 18).map(Person::getName).collect(Collectors.toList());

📦 Optional Class

Optional represents value that may or may not exist. Replaces null checks. Use isPresent(), orElse(), ifPresent().
Real Example: Optional<User> user = userMap.get("123"); user.ifPresent(u → System.out.println(u.getName()));

🕐 Date & Time API

LocalDate (date only), LocalTime (time only), LocalDateTime (both), ZonedDateTime (with timezone). Immutable unlike old Date.
Real Example: Meeting at 2 PM today: LocalDateTime meeting = LocalDateTime.now().withHour(14).withMinute(0);

4. Multithreading & Concurrency

🔄 Thread Creation

Extend Thread class (single inheritance limit) or implement Runnable interface (preferred). Use Callable for return values & exceptions.
Real Example: Download multiple files concurrently: create threads for each file download instead of sequential.

🔒 Synchronization

synchronized methods/blocks prevent race conditions. Only one thread enters at a time. Slower but safe.
Real Example: Bank account withdrawal: synchronized method prevents two withdrawals happening simultaneously from one account.

💼 Executor Framework

Thread pools manage threads efficiently. Fixed (fixed size), Cached (grows as needed), Scheduled (delayed/recurring tasks), Single (one thread).
Real Example: Web server with 100 requests: use ExecutorService executor = Executors.newFixedThreadPool(10); limits threads to 10.

🔗 CompletableFuture

Async programming without callbacks. Chain operations with thenApply(), thenAccept(), thenCombine().
Real Example: Fetch user data, then fetch orders asynchronously: getUser().thenCompose(user → getOrders(user.id));

💾 Java Memory Model

Defines visibility of shared variable changes between threads. volatile keyword ensures changes visible immediately.
Real Example: Flag to stop thread loop: make it volatile boolean stopFlag; so thread sees update immediately.

5. Memory Management & JVM Internals

⚙️ JVM Architecture

Classloader loads classes, Execution engine converts bytecode to machine code, Runtime provides memory areas (Heap, Stack, etc).
Real Example: When you run java MyApp, ClassLoader loads MyApp.class, executes main() method.

🧠 Heap vs Stack

Stack is LIFO (method calls, local variables - fast, limited). Heap is dynamic (objects - slower, large). Stack cleaned automatically, Heap needs GC.
Real Example: int x = 5; stored on stack. User user = new User(); reference on stack, object on heap.

🗑️ Garbage Collection

GC identifies unreferenced objects, cleans memory. G1GC recommended for heaps > 4GB. Gens: Eden (young objects), Survivor, Tenured (old objects).
Real Example: Creating millions of objects in a loop: GC periodically cleans unused objects, else OutOfMemoryError.

🔗 Reference Types

Strong (normal), Weak (GC collects if only weak refs), Soft (GC collects if memory needed), Phantom (no value, notification on GC).
Real Example: Cache: use WeakReference so cache doesn't prevent GC if memory needed.

6. Input/Output (I/O) & Networking

📖 File I/O

FileReader reads character by character, BufferedReader reads line by line (faster). FileInputStream for binary data.
Real Example: Read config file line by line: BufferedReader br = new BufferedReader(new FileReader("config.txt"));

💾 Serialization

Convert objects to bytes for storage/transmission. Use serialVersionUID for version control. transient excludes fields from serialization.
Real Example: Save user session to disk or send over network: serialize User object, deserialize on retrieval.

🚀 NIO (Non-blocking I/O)

Channels & Buffers for non-blocking operations. Selectors allow handling many connections with few threads.
Real Example: High-performance web server handling 10,000 connections: NIO is much better than blocking I/O.

7. Design Patterns

👤 Singleton

Ensure only one instance exists. Use private constructor, static getInstance(). Double-checked locking for thread safety.
Real Example: Database connection pool, Logger, ConfigManager - only one instance needed.

🏭 Factory Pattern

Create objects without specifying exact classes. Central place for object creation, easy to change implementation.
Real Example: DatabaseFactory.getDatabase("mysql") returns MySQL or PostgreSQL implementation.

🛠️ Builder Pattern

Construct complex objects step by step. Fluent interface, optional parameters, immutable result.
Real Example: new User.Builder().name("John").email("john@example.com").age(30).build();

👀 Observer Pattern

Notify multiple objects about state changes. Subject (observable) notifies observers when state changes.
Real Example: Stock price changes: notify all investors subscribed to that stock.

8. Modern Java Features (Java 9 - 21)

📦 Java 9 Modules

Encapsulate packages, explicit exports. Large projects benefit from strong encapsulation and clear dependencies.
Real Example: Large enterprise application divided into modules like payment-module, user-module for better organization.

✨ Java 10 - Local Variable Type Inference (var)

var list = new ArrayList<String>(); instead of ArrayList<String> list = .... Type inferred from right-hand side.
Real Example: var users = userRepository.findAll(); cleaner than explicitly typing the generic.

📝 Java 14 - Records

Immutable data carriers. Auto-generates constructor, equals(), hashCode(), toString(). Replaces Java Beans boilerplate.
Real Example: record User(String name, String email, int age) {} instead of 50 lines of boilerplate code.

🔐 Java 16 - Pattern Matching for instanceof

Reduces casting boilerplate. if (obj instanceof String s) { s.length(); }
Real Example: No more if (obj instanceof String) { String s = (String) obj; } three-liner.

⚡ Java 21 - Virtual Threads (Project Loom)

Millions of lightweight threads instead of OS threads. Game changer for high-concurrency applications.
Real Example: Web server handling 1 million concurrent connections: use virtual threads instead of 1 million OS threads.

9. Testing & Quality

🧪 JUnit 5

@Test marks test method, @BeforeEach setup before each test, @AfterEach cleanup, @DisplayName for readable names.
Real Example: Test login: @Test @DisplayName("Valid login returns user") void testLogin() { ... }

🎭 Mockito

Mock external dependencies. @Mock creates mock, @InjectMocks injects into test class. when-then define behavior.
Real Example: Test UserService without database: mock UserRepository, control database responses.

10. Database Connectivity (JDBC & ORM)

🔗 JDBC

Java Database Connectivity. DriverManager → Connection → Statement → ResultSet. Use PreparedStatement to prevent SQL injection.
Real Example: Fetch user by ID: PreparedStatement ps = conn.prepareStatement("SELECT * FROM users WHERE id=?"); ps.setInt(1, userId);

🏢 Hibernate/JPA - Entity Lifecycle

Transient (new, not in DB), Persistent (tracked by session), Detached (session closed), Removed (marked for deletion).
Real Example: Create user → session.save() → Persistent. Close session → Detached. Changes not auto-saved.

⚡ Fetch Types - Lazy vs Eager

Lazy loads related data on-demand (efficient, solves N+1), Eager loads immediately (wastes memory if unused).
Real Example: User with 100 Orders: use Lazy loading unless you always need orders, else extra memory waste.
