🍃 Spring Boot Essential Topics

Complete Guide with Real-World Examples

1. Core Spring Boot Fundamentals

⚙️ Auto-Configuration

@EnableAutoConfiguration scans classpath, auto-configures beans based on present libraries. Classpath scanning using spring.factories file. Override with @Bean.
Real Example: Add spring-boot-starter-data-jpa → Hibernate auto-configured, no manual config needed.

📦 Starters

Simplified dependency management. spring-boot-starter-web includes tomcat, spring-mvc, etc. Version managed by Spring Boot.
Real Example: Instead of adding 20 dependencies manually, use starter: dependencies align perfectly.

💉 Dependency Injection & Bean Scopes

Constructor injection (best), Setter injection, Field injection (discouraged - hard to test). Scopes: Singleton (default), Prototype (new each time), Request, Session.
Real Example: public UserService(UserRepository repo) { this.repo = repo; } constructor injection, easy to test with mock.

🔄 Bean Lifecycle

@PostConstruct runs after bean creation (init logic), @PreDestroy before bean destroyed (cleanup). Useful for resource management.
Real Example: Database connection pool: @PostConstruct initializes connections, @PreDestroy closes pool.

2. Essential Annotations

🷷 Stereotype Annotations

@Component (generic), @Service (business logic), @Repository (data access), @Controller (MVC), @RestController (REST API).
Real Example: UserService class: @Service annotation, Spring auto-registers as bean.

⚙️ Configuration Annotations

@Configuration marks class as bean factory, @Bean defines bean, @Import includes other config classes.
Real Example: Create DatabaseConfig class with @Bean DataSource method, returns configured datasource.

💉 Injection Annotations

@Autowired injects dependency (by type), @Qualifier specifies which bean if multiple, @Primary default when ambiguous.
Real Example: Two UserRepository implementations: mark one as @Primary or use @Qualifier("mysql").

📝 Property Annotations

@Value injects properties (environment variables, config files), @ConfigurationProperties binds class to properties prefix with validation.
Real Example: @Value("${app.name}") injects value from application.properties.

🚀 @SpringBootApplication

Combines @Configuration, @EnableAutoConfiguration, @ComponentScan. Single annotation for startup.
Real Example: Main class: @SpringBootApplication public class App { public static void main(String[] args) { SpringApplication.run(App.class); }}

3. Building RESTful APIs

🎯 Request Mapping

@GetMapping, @PostMapping, @PutMapping, @DeleteMapping, @PatchMapping map HTTP methods to handlers.
Real Example: @GetMapping("/users/{id}") public User getUser(@PathVariable int id) { ... }

📥 Input Annotations

@PathVariable from URL path, @RequestParam from query string, @RequestBody from JSON, @RequestHeader from headers.
Real Example: @PostMapping("/users") void createUser(@RequestBody User user, @RequestHeader String authorization) { ... }

📤 Response Entity

ResponseEntity<T> wraps response with HTTP status, headers. Better than returning plain objects.
Real Example: return new ResponseEntity<>(user, HttpStatus.OK); or ResponseEntity.created(uri).body(user); for 201 status.

⚠️ Exception Handling

@ControllerAdvice global exception handler, @ExceptionHandler maps exception to response. Centralized, consistent error responses.
Real Example: @ExceptionHandler(UserNotFoundException.class) public ResponseEntity handle(UserNotFoundException e) { ... return new ResponseEntity<>(error, NOT_FOUND); }

✅ Validation

@Valid triggers validation, use Jakarta Validation annotations: @NotNull, @Size, @Email, @Positive, etc.
Real Example: @PostMapping void createUser(@Valid @RequestBody User user) { ... } validates email format, non-null fields.

4. Spring Data JPA & Database Access

📦 Repository Types

CrudRepository (CRUD operations), PagingAndSortingRepository (+ pagination), JpaRepository (+ batch operations - most used).
Real Example: public interface UserRepository extends JpaRepository<User, Long> { ... } auto-generates save(), findById(), delete().

🔍 Query Methods

Derived queries from method names: findByEmail, findByAgeGreaterThan, findByNameContains. Or use @Query for JPQL/native SQL.
Real Example: List<User> findByEmailContainsAndIsActive(String email, boolean active) auto-generates WHERE clause.

📋 Entity Mapping

@Entity marks class as entity, @Table specifies table name, @Id primary key, @GeneratedValue auto-increment, @Column customizes column.
Real Example: @Entity @Table(name="users") class User { @Id @GeneratedValue Long id; @Column(unique=true) String email; }

🔗 Relationships - Lazy vs Eager

Lazy loads related data on-demand (efficient), Eager loads immediately (wasteful). @OneToMany(fetch=FetchType.LAZY) default, .EAGER loads all.
Real Example: User with 1000 Orders: lazy loading → select user → select orders only if accessed. Eager → load all orders even if not used.

💾 Transactions

@Transactional manages transactions. Propagation: REQUIRED (default, reuse or create), REQUIRES_NEW (new transaction). Isolation levels: READ_COMMITTED (default), SERIALIZABLE (strict).
Real Example: Transfer money: @Transactional ensures both debit + credit happen or neither.

5. Spring Security

🔐 SecurityFilterChain

Filters intercept requests, check authentication/authorization. Order matters: Authentication → Authorization. Chain configured in @EnableWebSecurity.
Real Example: Request → AuthenticationFilter (checks credentials) → AuthorizationFilter (checks permissions) → Controller.

👤 Authentication

AuthenticationManager orchestrates auth, UserDetailsService loads user from DB, UsernamePasswordAuthenticationToken holds credentials.
Real Example: Login: AuthenticationManager calls UserDetailsService → checks password → creates authenticated token → stores in SecurityContext.

🔑 Authorization

Role-based access control (RBAC). @PreAuthorize("hasRole('ADMIN')") restricts to admins. requestMatchers configure URL permissions.
Real Example: Admin endpoints: http.authorizeHttpRequests().requestMatchers("/admin/**").hasRole("ADMIN")

🎫 JWT (JSON Web Tokens)

Stateless authentication. Token contains user info (base64 encoded). Server verifies signature. Mobile apps use JWT (no session cookies).
Real Example: Mobile app: login → receive JWT → send in Authorization header for API calls.

🌐 CORS Configuration

Allow cross-origin requests. @CrossOrigin annotation or global config. Frontend on different domain needs CORS.
Real Example: Web app (localhost:3000) calls API (localhost:8080): configure CORS to allow.

6. Testing

🧪 Test Annotations

@SpringBootTest loads full context (slow, integration test), @WebMvcTest tests only controllers (fast), @DataJpaTest tests repositories.
Real Example: Unit test UserService: @WebMvcTest(UserController.class) with MockMvc without loading entire app.

🎭 Mocking with Mockito

@Mock creates mock, @InjectMocks injects mocks into test class. when-thenReturn define behavior. verify assert calls.
Real Example: Test UserService without database: @Mock UserRepository repo; @InjectMocks UserService service; when(repo.findById(1)).thenReturn(Optional.of(user));

🧬 Integration Testing

Test multiple components together. @SpringBootTest loads entire app, test against real DB (use testcontainers) or H2 in-memory.
Real Example: Test user creation → save to DB → verify email sent (mock) → check DB contains user.

7. Microservices & Cloud Patterns

🔍 Service Discovery

Services register themselves (Eureka, Consul). Client calls service by name, discovery resolves to IP:port. Handles dynamic instance changes.
Real Example: OrderService calls UserService by name, discovery provides IP of available instance.

🚪 API Gateway

Single entry point for all services. Routes requests, handles auth, rate limiting. Spring Cloud Gateway is Spring's solution.
Real Example: Client calls gateway/users → routes to UserService, /orders → OrderService.

🛡️ Circuit Breaker (Resilience4j)

Prevent cascading failures. States: Closed (ok) → Open (failing) → Half-Open (testing). Fails fast, retries automatically.
Real Example: UserService calls PaymentService: fails 5 times → circuit opens → reject requests for 30s → half-open → test single request.

⚙️ Externalized Config

Spring Cloud Config: centralized server manages config for all services. Change config without redeploying.
Real Example: Update database URL in config server → all services pick up without restart.

💬 Inter-Service Communication

RestTemplate (deprecated), WebClient (non-blocking), FeignClient (declarative, like Retrofit). Choose non-blocking for high-concurrency.
Real Example: @FeignClient("user-service") interface UserClient { @GetMapping("/users/{id}") User getUser(@PathVariable Long id); }

8. Observability & Monitoring

📊 Actuator Endpoints

Expose application metrics & info. /actuator/health (liveness/readiness), /actuator/metrics, /actuator/info (app info).
Real Example: Kubernetes calls /health to check if pod is alive, restart if unhealthy.

📈 Micrometer

Collects metrics (JVM, HTTP, custom). Exports to Prometheus, Grafana, etc. @Timed for method metrics.
Real Example: @Timed public void processOrder() { ... } auto-measures execution time, count, errors.

📝 Logging

SLF4J facade, Logback implementation. MDC (Mapped Diagnostic Context) for tracing. Log levels: TRACE, DEBUG, INFO, WARN, ERROR.
Real Example: MDC.put("requestId", uuid) → all logs in request include requestId, easy tracing across services.

9. Scheduling & Async

⏰ Scheduled Tasks

@EnableScheduling enables scheduling, @Scheduled with cron or fixed delay. Runs on single thread by default.
Real Example: @Scheduled(cron="0 0 * * * *") void dailyCleanup() { ... } runs daily at midnight.

⚡ Async Processing

@EnableAsync enables async, @Async on method runs in separate thread pool. Returns CompletableFuture or void.
Real Example: Send welcome email async: @Async void sendWelcomeEmail(User user) { ... } doesn't block response.

10. Profiles & Deployment

🔧 Profiles

Separate config per environment: dev, test, prod. spring.profiles.active=prod activates profile. Loads application-prod.properties.
Real Example: Dev uses H2 DB, Prod uses PostgreSQL. Config differs by profile.

📦 Packaging

JAR packaged with embedded Tomcat (standalone), WAR deployed to external app server (legacy). JAR recommended for modern apps.
Real Example: JAR: java -jar app.jar runs standalone. WAR: deploy to Tomcat server.

🐳 Docker Containerization

Dockerfile multistage build: compile in first stage, copy fat JAR to final image. Minimize image size.
Real Example: Dockerfile uses JDK for build, JRE for runtime, reduces size from 500MB to 200MB.
