1How the Server Works (Request–Response Cycle)

The Request-Response Cycle is the fundamental communication pattern between clients (browsers, mobile apps) and servers. When you type a URL or click a button, your device sends a request to a server, which processes it and sends back a response.


The cycle works in these steps:

  1. DNS Resolution: Browser finds the server's IP address from the domain name
  2. TCP Connection: A connection is established (3-way handshake)
  3. Request Sent: Client sends HTTP request with method, headers, and body
  4. Server Processing: Server receives, processes, queries database if needed
  5. Response Sent: Server sends back status code, headers, and body
  6. Connection Closed: Connection terminates (or stays alive for keep-alive)

🌍 Real-Life Example: Ordering Food at a Restaurant

Think of a restaurant:

  • You (Client): Place an order (Request)
  • Waiter (HTTP Protocol): Takes your order to the kitchen
  • Kitchen (Server): Prepares your food (Processing)
  • Waiter returns with food (Response): Your meal is delivered
  • Bill & Payment (Status Code): Success (200) if everything's fine, or "Item not available" (404)

// Java Spring Boot - Request-Response Cycle Example
import org.springframework.web.bind.annotation.*;
import org.springframework.http.ResponseEntity;
import javax.servlet.http.HttpServletRequest;

@RestController
@RequestMapping("/api/orders")
public class OrderController {

    // Handling a GET request
    @GetMapping("/{orderId}")
    public ResponseEntity<Order> getOrder(
            @PathVariable Long orderId,
            HttpServletRequest request) {
        
        // Request Phase - Extract information
        String clientIP = request.getRemoteAddr();
        String userAgent = request.getHeader("User-Agent");
        System.out.println("Request from: " + clientIP);
        
        // Processing Phase - Business Logic
        Order order = orderService.findById(orderId);
        
        if (order == null) {
            // Response Phase - Not Found
            return ResponseEntity.notFound().build();
        }
        
        // Response Phase - Success
        return ResponseEntity.ok(order);
    }

    // Handling a POST request
    @PostMapping
    public ResponseEntity<Order> createOrder(@RequestBody OrderRequest request) {
        // Request body is automatically deserialized
        Order newOrder = orderService.create(request);
        
        // Response with 201 Created status
        return ResponseEntity
            .status(HttpStatus.CREATED)
            .body(newOrder);
    }
}

📌 Key Points to Remember

  • Every web interaction follows the request-response pattern
  • Requests contain: Method, URL, Headers, Body (optional)
  • Responses contain: Status Code, Headers, Body
  • The server is stateless - each request is independent
  • Understanding this cycle is crucial for debugging network issues

2REST API Design Principles

REST (Representational State Transfer) is an architectural style for designing networked applications. RESTful APIs use HTTP requests to perform CRUD operations (Create, Read, Update, Delete) on resources.


Core REST Principles:

  • Stateless: Each request contains all information needed; server doesn't store client state
  • Client-Server Separation: Client and server evolve independently
  • Uniform Interface: Consistent way to interact with resources using standard HTTP methods
  • Resource-Based: Everything is a resource identified by URIs
  • Cacheable: Responses can be cached to improve performance
  • Layered System: Client can't tell if connected directly to end server

🌍 Real-Life Example: Library Management System

Think of a public library:

  • Resources: Books, Members, Borrowings (nouns, not actions)
  • GET /books: View catalog (like browsing shelves)
  • POST /books: Add new book (librarian adds to collection)
  • PUT /books/123: Update book info (correct a typo in title)
  • DELETE /books/123: Remove damaged book
  • GET /members/456/borrowings: See what books a member borrowed

import org.springframework.http.HttpStatus;
import java.net.URI;
import java.util.List;

@RestController
@RequestMapping("/api/v1/books")  // Version in URL, resource is plural noun
public class BookController {

    private final BookService bookService;

    // Constructor injection (best practice)
    public BookController(BookService bookService) {
        this.bookService = bookService;
    }

    // GET /api/v1/books - Get all books (with pagination)
    @GetMapping
    public ResponseEntity<Page<Book>> getAllBooks(
            @RequestParam(defaultValue = "0") int page,
            @RequestParam(defaultValue = "10") int size,
            @RequestParam(required = false) String genre) {
        
        Page<Book> books = bookService.findAll(page, size, genre);
        return ResponseEntity.ok(books);
    }

    // GET /api/v1/books/{id} - Get single book
    @GetMapping("/{id}")
    public ResponseEntity<Book> getBookById(@PathVariable Long id) {
        return bookService.findById(id)
            .map(ResponseEntity::ok)
            .orElse(ResponseEntity.notFound().build());
    }

    // POST /api/v1/books - Create new book
    @PostMapping
    public ResponseEntity<Book> createBook(@Valid @RequestBody BookDTO bookDTO) {
        Book created = bookService.create(bookDTO);
        URI location = URI.create("/api/v1/books/" + created.getId());
        return ResponseEntity.created(location).body(created);
    }

    // PUT /api/v1/books/{id} - Full update
    @PutMapping("/{id}")
    public ResponseEntity<Book> updateBook(
            @PathVariable Long id, 
            @Valid @RequestBody BookDTO bookDTO) {
        return bookService.update(id, bookDTO)
            .map(ResponseEntity::ok)
            .orElse(ResponseEntity.notFound().build());
    }

    // PATCH /api/v1/books/{id} - Partial update
    @PatchMapping("/{id}")
    public ResponseEntity<Book> partialUpdateBook(
            @PathVariable Long id,
            @RequestBody Map<String, Object> updates) {
        return bookService.partialUpdate(id, updates)
            .map(ResponseEntity::ok)
            .orElse(ResponseEntity.notFound().build());
    }

    // DELETE /api/v1/books/{id} - Delete book
    @DeleteMapping("/{id}")
    public ResponseEntity<Void> deleteBook(@PathVariable Long id) {
        if (bookService.delete(id)) {
            return ResponseEntity.noContent().build();
        }
        return ResponseEntity.notFound().build();
    }

    // Nested resource: GET /api/v1/books/{id}/reviews
    @GetMapping("/{id}/reviews")
    public ResponseEntity<List<Review>> getBookReviews(@PathVariable Long id) {
        List<Review> reviews = bookService.getReviews(id);
        return ResponseEntity.ok(reviews);
    }

📌 REST API Best Practices

  • Use nouns for resources, not verbs (✓ /books, ✗ /getBooks)
  • Use plural nouns (✓ /users, ✗ /user)
  • Use HTTP methods to define actions (GET, POST, PUT, PATCH, DELETE)
  • Return appropriate status codes (200, 201, 204, 400, 404, 500)
  • Version your API (/api/v1/, /api/v2/)
  • Use query parameters for filtering, sorting, pagination
  • Use consistent response format across all endpoints

3HTTP Methods & Status Codes

HTTP Methods (also called verbs) indicate the desired action to perform on a resource. Status Codes are three-digit numbers returned by the server to indicate the result of the request.

// Java Spring Boot - HTTP Methods & Status Codes
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api/v1/accounts")
public class BankAccountController {

    // GET - Retrieve (Safe & Idempotent)
    // Status: 200 OK (success), 404 Not Found (account doesn't exist)
    @GetMapping("/{accountId}/balance")
    public ResponseEntity<?> getBalance(@PathVariable String accountId) {
        try {
            Account account = accountService.findById(accountId);
            if (account == null) {
                return ResponseEntity
                    .status(HttpStatus.NOT_FOUND)  // 404
                    .body(new ErrorResponse("Account not found"));
            }
            return ResponseEntity.ok(account.getBalance());  // 200
        } catch (Exception e) {
            return ResponseEntity
                .status(HttpStatus.INTERNAL_SERVER_ERROR)  // 500
                .body(new ErrorResponse("Server error"));
        }
    }

    // POST - Create (Not Idempotent)
    // Status: 201 Created (success), 400 Bad Request (invalid data)
    @PostMapping
    public ResponseEntity<?> createAccount(@Valid @RequestBody AccountDTO dto) {
        try {
            Account created = accountService.create(dto);
            return ResponseEntity
                .status(HttpStatus.CREATED)  // 201
                .body(created);
        } catch (DuplicateAccountException e) {
            return ResponseEntity
                .status(HttpStatus.CONFLICT)  // 409
                .body(new ErrorResponse("Account already exists"));
        } catch (ValidationException e) {
            return ResponseEntity
                .status(HttpStatus.BAD_REQUEST)  // 400
                .body(new ErrorResponse(e.getMessage()));
        }
    }

    // PUT - Full Update (Idempotent)
    // Status: 200 OK (updated), 201 Created (if created new)
    @PutMapping("/{accountId}")
    public ResponseEntity<Account> updateAccount(
            @PathVariable String accountId,
            @Valid @RequestBody AccountDTO dto) {
        
        Optional<Account> existing = accountService.findById(accountId);
        
        if (existing.isPresent()) {
            Account updated = accountService.update(accountId, dto);
            return ResponseEntity.ok(updated);  // 200
        } else {
            Account created = accountService.create(dto);
            return ResponseEntity
                .status(HttpStatus.CREATED)  // 201
                .body(created);
        }
    }

    // PATCH - Partial Update (Idempotent)
    // Status: 200 OK, 400 Bad Request, 404 Not Found
    @PatchMapping("/{accountId}")
    public ResponseEntity<?> partialUpdate(
            @PathVariable String accountId,
            @RequestBody Map<String, Object> updates) {
        
        if (!accountService.exists(accountId)) {
            return ResponseEntity.notFound().build();  // 404
        }
        
        Account updated = accountService.patch(accountId, updates);
        return ResponseEntity.ok(updated);  // 200
    }

    // DELETE - Remove (Idempotent)
    // Status: 204 No Content (success), 404 Not Found
    @DeleteMapping("/{accountId}")
    public ResponseEntity<Void> deleteAccount(@PathVariable String accountId) {
        if (!accountService.exists(accountId)) {
            return ResponseEntity.notFound().build();  // 404
        }
        
        accountService.delete(accountId);
        return ResponseEntity.noContent().build();  // 204
    }

    // POST for action (non-CRUD operation)
    @PostMapping("/{accountId}/transfer")
    public ResponseEntity<?> transferMoney(
            @PathVariable String accountId,
            @RequestBody TransferRequest request) {
        
        try {
            Transaction tx = accountService.transfer(
                accountId, 
                request.getToAccount(), 
                request.getAmount()
            );
            return ResponseEntity.ok(tx);  // 200
        } catch (InsufficientFundsException e) {
            return ResponseEntity
                .status(HttpStatus.UNPROCESSABLE_ENTITY)  // 422
                .body(new ErrorResponse("Insufficient funds"));
        } catch (AccountNotFoundException e) {
            return ResponseEntity
                .status(HttpStatus.NOT_FOUND)  // 404
                .body(new ErrorResponse("Account not found"));
        }
    }
}

SUCCESS (2xx):
  200 OK - Standard successful response

  202 Accepted - Request accepted for processing (async)

REDIRECTION (3xx):

  302 Found - Temporary redirect
  304 Not Modified - Cached version is still valid

CLIENT ERRORS (4xx):
  400 Bad Request - Invalid syntax/validation failed
  401 Unauthorized - Authentication required
  403 Forbidden - Authenticated but not authorized
  404 Not Found - Resource doesn't exist
  405 Method Not Allowed - HTTP method not supported

SERVER ERRORS (5xx):
  500 Internal Server Error - Generic server error
  502 Bad Gateway - Invalid response from upstream
  503 Service Unavailable - Server temporarily unavailable
  504 Gateway Timeout - Upstream timeout

📌 Key Points to Remember

  • Idempotent: Multiple identical requests have same effect (GET, PUT, PATCH, DELETE)
  • Safe: Request doesn't modify resources (GET, HEAD, OPTIONS)
  • Use 201 Created for POST that creates resources
  • Use 204 No Content for successful DELETE
  • Use 400 for client mistakes, 500 for server issues
  • Always validate input before processing to return appropriate 4xx errors

4Middleware & Request Flow

Middleware is software that sits between the client request and server response, processing requests as they flow through the application. Middleware functions have access to the request object, response object, and the next middleware in the chain.


Request Flow: Client → Middleware 1 → Middleware 2 → ... → Controller → Response


Common Middleware Uses:

  • Logging: Record request details
  • Authentication: Verify user identity
  • Authorization: Check permissions
  • Validation: Validate input data
  • Compression: Compress responses
  • CORS: Handle cross-origin requests
  • Rate Limiting: Prevent abuse

🌍 Real-Life Example: Airport Security Check

Think of going through airport security:

  • Ticket Check (Authentication): Verify you have a valid ticket
  • ID Verification (Authorization): Check if you're allowed on this flight
  • Metal Detector (Validation): Scan for prohibited items
  • Baggage Scan (Logging): Record what's in your luggage
  • Temperature Check (Health Middleware): Health screening
  • Boarding Gate (Controller): Finally access the plane (resource)

Each checkpoint can reject you (error response) or let you pass through (next middleware).

// Java Spring Boot - Middleware using Filters and Interceptors

// 1. FILTER - Lowest level, works on raw request/response
import javax.servlet.*;
import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;
import java.io.IOException;

@Component
@Order(1)  // Execution order
public class LoggingFilter implements Filter {

    private static final Logger logger = LoggerFactory.getLogger(LoggingFilter.class);

    @Override
    public void doFilter(ServletRequest request, ServletResponse response, FilterChain chain)
            throws IOException, ServletException {
        
        HttpServletRequest httpRequest = (HttpServletRequest) request;
        HttpServletResponse httpResponse = (HttpServletResponse) response;
        
        long startTime = System.currentTimeMillis();
        String requestId = UUID.randomUUID().toString();
        
        // Before processing
        logger.info("Request START: {} {} - ID: {}", 
            httpRequest.getMethod(), 
            httpRequest.getRequestURI(),
            requestId);
        
        // Add request ID to response header
        httpResponse.setHeader("X-Request-ID", requestId);
        
        try {
            // Pass to next filter/controller
            chain.doFilter(request, response);
        } finally {
            // After processing
            long duration = System.currentTimeMillis() - startTime;
            logger.info("Request END: {} {} - Status: {} - Duration: {}ms", 
                httpRequest.getMethod(),
                httpRequest.getRequestURI(),
                httpResponse.getStatus(),
                duration);
        }
    }
}

// 2. AUTHENTICATION FILTER
@Component
@Order(2)
public class AuthenticationFilter extends OncePerRequestFilter {

    @Autowired
    private JwtTokenProvider tokenProvider;

    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                    HttpServletResponse response,
                                    FilterChain filterChain)
            throws ServletException, IOException {
        
        String token = extractToken(request);
        
        if (token != null && tokenProvider.validateToken(token)) {
            UserDetails userDetails = tokenProvider.getUserDetails(token);
            UsernamePasswordAuthenticationToken authentication = 
                new UsernamePasswordAuthenticationToken(
                    userDetails, null, userDetails.getAuthorities());
            
            SecurityContextHolder.getContext().setAuthentication(authentication);
        }
        
        filterChain.doFilter(request, response);
    }

    private String extractToken(HttpServletRequest request) {
        String bearerToken = request.getHeader("Authorization");
        if (bearerToken != null && bearerToken.startsWith("Bearer ")) {
            return bearerToken.substring(7);
        }
        return null;
    }
}

    public boolean preHandle(HttpServletRequest request, 
                            HttpServletResponse response,
                            Object handler) throws Exception {
        
        // Skip for non-controller handlers
        if (!(handler instanceof HandlerMethod)) {
            return true;
        }
        
        HandlerMethod handlerMethod = (HandlerMethod) handler;
        RequiresRole annotation = handlerMethod.getMethodAnnotation(RequiresRole.class);
        
        if (annotation != null) {
            Authentication auth = SecurityContextHolder.getContext().getAuthentication();
            
            if (!hasRequiredRole(auth, annotation.value())) {
                response.setStatus(HttpStatus.FORBIDDEN.value());
                response.getWriter().write("{\"error\": \"Access denied\"}");
                return false;  // Stop the request
            }
        }
        
        return true;  // Continue to controller
    }

    @Override
    public void postHandle(HttpServletRequest request, 
                          HttpServletResponse response,
                          Object handler, 
                          ModelAndView modelAndView) {
        // After controller, before view rendering
    }

    @Override
    public void afterCompletion(HttpServletRequest request,
                               HttpServletResponse response,
                               Object handler, 
                               Exception ex) {
        // After complete request processing
    }
}

class LoggingMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next: Callable) -> Response:
        # Before processing
        request_id = str(uuid.uuid4())
        start_time = time.time()
        
        logger.info(f"Request START: {request.method} {request.url.path} - ID: {request_id}")
        
        # Add request ID to state (accessible in route handlers)
        request.state.request_id = request_id
        
        # Process the request
        response = await call_next(request)
        
        # After processing
        duration = time.time() - start_time
        logger.info(
            f"Request END: {request.method} {request.url.path} "
            f"- Status: {response.status_code} - Duration: {duration:.3f}s"
        )
        
        # Add request ID to response header
        response.headers["X-Request-ID"] = request_id
        
        return response

# 2. AUTHENTICATION MIDDLEWARE
class AuthenticationMiddleware(BaseHTTPMiddleware):
    PUBLIC_PATHS = ["/api/auth/login", "/api/auth/register", "/api/public", "/docs", "/openapi.json"]
    
    async def dispatch(self, request: Request, call_next: Callable) -> Response:
        # Skip authentication for public paths
        if any(request.url.path.startswith(path) for path in self.PUBLIC_PATHS):
            return await call_next(request)
        
        # Extract token from header
        auth_header = request.headers.get("Authorization")
        
        if not auth_header or not auth_header.startswith("Bearer "):
            return Response(
                content='{"error": "Missing or invalid authentication token"}',
                status_code=401,
                media_type="application/json"
            )
        
        token = auth_header[7:]  # Remove "Bearer " prefix
        
        try:
            # Verify token and get user
            user = await verify_jwt_token(token)
            request.state.user = user
        except TokenExpiredError:
            return Response(
                content='{"error": "Token expired"}',
                status_code=401,
                media_type="application/json"
            )
        except InvalidTokenError:
            return Response(
                content='{"error": "Invalid token"}',
                status_code=401,
                media_type="application/json"
            )
        
        return await call_next(request)

# 3. RATE LIMITING MIDDLEWARE
from collections import defaultdict
from datetime import datetime, timedelta

class RateLimitMiddleware(BaseHTTPMiddleware):
    def __init__(self, app, requests_per_minute: int = 60):
        super().__init__(app)
        self.requests_per_minute = requests_per_minute
        self.requests = defaultdict(list)  # IP -> [timestamps]
    
    async def dispatch(self, request: Request, call_next: Callable) -> Response:
        client_ip = request.client.host
        now = datetime.now()
        minute_ago = now - timedelta(minutes=1)
        
        # Clean old requests
        self.requests[client_ip] = [
            ts for ts in self.requests[client_ip] 
            if ts > minute_ago
        ]
        
        # Check rate limit
        if len(self.requests[client_ip]) >= self.requests_per_minute:
            return Response(
                content='{"error": "Rate limit exceeded. Try again later."}',
                status_code=429,
                media_type="application/json",
                headers={"Retry-After": "60"}
            )
        
        # Record this request
        self.requests[client_ip].append(now)
        
        return await call_next(request)

📌 Key Points to Remember

  • Middleware executes in the order it's registered
  • Each middleware can modify request/response or stop the chain
  • Use middleware for cross-cutting concerns (logging, auth, CORS)
  • Java uses Filters (low-level) and Interceptors (high-level)
  • Python/FastAPI uses BaseHTTPMiddleware or @app.middleware decorator
  • Keep middleware focused on single responsibility
  • Middleware should be fast - avoid blocking operations

5Authentication vs Authorization

Authentication (AuthN) answers: "Who are you?" - It verifies the identity of a user or system.


Authorization (AuthZ) answers: "What can you do?" - It determines what actions an authenticated user is allowed to perform.


Aspect Authentication Authorization
Question Who are you? What can you access?
Process Validates credentials Validates permissions
Order First (before authorization) Second (after authentication)
HTTP Status 401 Unauthorized 403 Forbidden
Data Used Credentials, tokens, biometrics Roles, permissions, policies

🌍 Real-Life Example: Office Building Access

Imagine entering your office building:

  • Authentication (at entrance): You swipe your ID card or scan fingerprint to prove you're an employee
  • Authorization (inside building):
    • Your card allows access to your department floor ✓
    • Your card doesn't open the server room door ✗
    • Your card doesn't access the executive floor ✗
    • IT admin's card opens server room ✓

401 Unauthorized: "I don't know who you are" (no ID card)

403 Forbidden: "I know who you are, but you can't enter here" (ID works but no permission)

// 3. JWT Token Provider
@Component
public class JwtTokenProvider {
    
    @Value("${jwt.secret}")
    private String jwtSecret;
    
    @Value("${jwt.access-token-expiration}")
    private long accessTokenExpiration;
    
    public String generateAccessToken(User user) {
        Date now = new Date();
        Date expiry = new Date(now.getTime() + accessTokenExpiration);
        
        return Jwts.builder()
            .setSubject(user.getUsername())
            .claim("roles", user.getRoles())
            .setIssuedAt(now)
            .setExpiration(expiry)
            .signWith(SignatureAlgorithm.HS512, jwtSecret)
            .compact();
    }
    
    public boolean validateToken(String token) {
        try {
            Jwts.parser().setSigningKey(jwtSecret).parseClaimsJws(token);
            return true;
        } catch (JwtException | IllegalArgumentException e) {
            return false;
        }
    }
    
    public String getUsernameFromToken(String token) {
        Claims claims = Jwts.parser()
            .setSigningKey(jwtSecret)
            .parseClaimsJws(token)
            .getBody();
        return claims.getSubject();
    }
}

    """Verify a password against its hash."""

def get_password_hash(password: str) -> str:
    """Hash a password."""

def create_access_token(data: dict, expires_delta: Optional[timedelta] = None) -> str:
    """Create JWT access token."""
    to_encode = data.copy()
    expire = datetime.utcnow() + (expires_delta or timedelta(minutes=15))
    to_encode.update({"exp": expire})
    return jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)

    if not user:
        return None
    if not verify_password(password, user.hashed_password):
        return None
    return user

# AUTHENTICATION dependency - "Who are you?"
async def get_current_user(token: str = Depends(oauth2_scheme)) -> User:
    """Extract and validate user from JWT token."""
    credentials_exception = HTTPException(
        status_code=status.HTTP_401_UNAUTHORIZED,  # AUTHENTICATION failure
        detail="Could not validate credentials",
        headers={"WWW-Authenticate": "Bearer"},
    )
    
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        username: str = payload.get("sub")
        if username is None:
            raise credentials_exception
    except JWTError:
        raise credentials_exception
    
    user = fake_users_db.get(username)
    if user is None:
        raise credentials_exception
    
    return user

def require_roles(allowed_roles: List[Role]):
    """Create authorization dependency for role-based access."""
    async def role_checker(current_user: User = Depends(get_current_active_user)) -> User:

            raise HTTPException(
                status_code=status.HTTP_403_FORBIDDEN,  # AUTHORIZATION failure
                detail="You don't have permission to access this resource"
            )
        return current_user
    return role_checker

        return current_user

        detail="You can only modify your own posts"

📌 Key Points to Remember

  • Authentication comes first, then Authorization
  • Use 401 Unauthorized for authentication failures
  • Use 403 Forbidden for authorization failures
  • Always hash passwords (bcrypt, argon2) - never store plain text
  • JWT tokens carry user identity and claims for stateless auth
  • Implement role-based (RBAC) or attribute-based (ABAC) access control
  • Use middleware/filters for authentication, annotations/dependencies for authorization
